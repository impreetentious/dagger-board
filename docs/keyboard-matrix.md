# Keyboard Matrix

| Operation | Key path |
| --- | --- |
| Add observed node | `N` |
| Cycle node focus | `Tab` or arrow keys |
| Move active node | `Alt` + arrow key |
| Start / complete an edge | `E`, then select a target node |
| Set exposure / outcome | `X` / `Y` |
| Set latent / selection kind | `L` / `S` |
| Delete active node | `Delete` or `Backspace` |
| Undo / redo | `Cmd/Ctrl+Z` / `Shift+Cmd/Ctrl+Z` |
| Show keyboard help | `?` |

Every action has a visible control as well; keyboard input is not a hidden
alternative interaction mode.
